# Datos marítimos

Ciencia de datos aplicada al sector marítimo: datos abiertos, análisis y visualización.

Cada carpeta amplía una publicación breve con más contexto, fuentes y, cuando procede, un notebook reproducible que puede abrirse en Google Colab.

| Nº | Tema | Contenido |
|---|---|---|
| 01 | [Buques oscuros: lo que el AIS no ve](01-buques-oscuros/) | Artículo ampliado con fuentes |
| 02 | [ERA5: el histórico del mar](02-era5-historico-del-mar/) | Artículo ampliado y notebook para calcular días de mala mar en un punto |

## Criterios

- Solo datos públicos y abiertos, siempre con su fuente.
- Los resultados y gráficos se generan ejecutando el código incluido.
- Contenido técnico y divulgativo, sin valoraciones políticas.
